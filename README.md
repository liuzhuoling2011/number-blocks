# 数字积木 · 第一集：一

面向幼儿（约 3–6 岁）的 HTML5 小游戏原型。用**原创**彩色数字积木，认识「一」——一块、一个、一棵。

> 本项目**不是** BBC / Blue Zoo / CBeebies《Numberblocks》的翻版或素材提取。角色造型、表情、场景、文案均为原创。教学节奏可参考常见「一集一个数学概念」的结构，但美术与商标均不使用官方内容。

## 在线试玩

https://liuzhuoling2011.github.io/number-blocks/

手机浏览器打开即可；支持触摸拖拽。加载后可离线继续玩本页。

## 第一集在教什么

- 「一」= 一块积木
- 场景里每样东西也是 1 个（太阳、树、蜜蜂）
- 从积木盒拖出**正好一块**放到虚线格子上，做出「一」
- 放错会轻轻弹回，没有失败惩罚

全程大约 1～2 分钟。

## 操作

1. 点「开始玩」
2. 点屏幕听「一」的自我介绍
3. 拖「一」到处走走；点太阳 / 树 / 蜜蜂，看到数字 **1**
4. 从左下角积木盒拖出一块红方块，放到中间虚线格
5. 过关庆祝；可「再玩一次」。下一集「二」按钮暂未开放

## 「一集一关」路线图（规划）

| 集 | 概念 | 玩法草案 |
|----|------|----------|
| 1 一 | 认识 1 | 本仓库已实现 |
| 2 二 | 1+1=2，合与分 | 两块粘在一起变「二」，可再拆开 |
| 3 三 | 数到 3 | 排队、搭高塔 |
| … | … | 凑十、加倍、平方等后续再开 |

## 技术

- 单页 `index.html` + Canvas 绘制（无外部图片依赖）
- `devicePixelRatio` 适配高分屏
- 鼠标 + 触摸；大热区
- 简体中文 UI

## 本地打开

```bash
cd number-blocks
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

也可直接双击打开 `index.html`。
