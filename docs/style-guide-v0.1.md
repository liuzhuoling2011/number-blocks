# 数字积木 · 风格规范 v0.1（仅 One）

> 状态：**已确认**（灵哥 2026-10-25 通过 One 造型）。对齐现网程序化「一」（`assets.js` / `tex.js`）；git 由小灵统一安排。  
> 气质：软塑料教育积木、明亮、圆润、非写实。  
> 美术原创；配色受 Numberblocks 启发，**不抄写版权几何/贴图/字体**。  
> 本轮范围：**One 标准块 + 极简 pad**；bee / tree / sun 后置。

## 1. 比例基准

| 项 | 值 | 说明 |
|---|---|---|
| 单元边长 `size` | `1.05` 世界单位 | One 单体；后续多块角色按同单元堆叠 |
| 原点 | 底面中心 = `(0, 0, 0)` | 脚底贴地；身体中心在 `y = size/2` |
| 站姿 | Y-up，正面朝 **+Z** | 五官与徽章在 +Z 面 |
| 接触阴影（可选） | 圆盘 r≈`0.55`，黑、opacity≈`0.28` | 可读站姿；可运行时加，GLB 内可不含 |

## 2. 圆角参数

| 部件 | 几何 | segments | radius |
|---|---|---|---|
| 身体 | RoundedBox `size³` | `8` | `0.16`（约 size×0.15） |
| 小脚 | RoundedBox `0.28 × 0.12 × 0.36` | `3` | `0.04` |

- 忌锐边；圆角要在中近距清晰可读。
- 脚对称放置：x = `±0.22`，y≈`0.05`，z≈`0.06`。

## 3. 配色（One 红色系）

| 用途 | Hex | 备注 |
|---|---|---|
| 身体主色 | `#e85a48` | albedo 中心；可有顶亮 `#ff8f7a` → 底暗 `#b83227` 渐变 |
| 小脚 | `#c0392b` | 略深于身体，增强站姿剪影 |
| 徽章底 | `#fff8e8` | 奶油白圆盘 |
| 徽章描边 / 数字「1」 | `#c0392b` | 与脚同系 |
| 虹膜 / 微笑 | `#1a2433` / `#1a2430` | 深炭蓝，非纯黑 |
| 眼白 | `#fffef8` | 暖白 |
| 徽章 emissive | `#ffe8c8` × `0.12` | 轻暖光，勿过曝 |

## 4. 边缘高光 / 塑料 PBR

| 参数 | 值 |
|---|---|
| 材质 | `MeshStandardMaterial`（塑料） |
| roughness | `0.42`（身体）；脚 ≈`0.55` |
| metalness | `0.06`（身体）；脚 ≈`0.05` |
| envMapIntensity | ≈`0.55`（有环境贴图时；GLB 可省略 envMap，运行时挂） |
| normalScale | ≈`(0.35, 0.35)`（若带 soft normal） |

边缘高光约定（albedo 内烘焙即可）：

- 内缘浅色描边（约 `rgba(255,220,200,0.18)`）
- 外缘轻微磨蚀暗边（约 `rgba(90,20,15,0.22)`）
- 顶部高光条（约 `rgba(255,255,255,0.16)`）
- **禁止**强金属 / 镜面写实

## 5. 五官与徽章规则（本项目采用）

本项目 **采用立体五官 + 正面数字徽章**，不用整脸表情贴图替代立体件。

### 5.1 脸组

- 挂在身体前方：相对 body 约 `(0, +0.02, size/2 + 0.01)`
- 可选透明脸平面 `0.78×0.78`（腮红等软细节）；**眼球与微笑必须是立体网格**

### 5.2 立体眼球

- 白球半径 ≈`0.09`，略扁 `scale (1, 1.15, 0.7)`
- 左右间距 x = `±0.16`，y≈`0.06`，突出 z≈`0.04`
- 虹膜球半径 ≈`0.055`，色 `#1a2433`
- 高光点：小白球 / BasicMaterial

### 5.3 微笑

- `TorusGeometry` 弧段：半径 `0.16`、管径 `0.022`、弧长约 `0.7π`
- 位置相对脸组约 `(0, -0.12, 0.05)`，绕 Z 转 `π` 使弧口朝上

### 5.4 数字徽章

- 圆形，半径 ≈`0.17`（直径约 `0.34`）
- 位置相对 body：右下 `(0.34, -0.3, size/2 + 0.02)`
- 内容：奶油底 + 朱红描边 + 数字 **「1」**（原创字形，勿嵌版权字体文件）
- 轻 emissive 如上表

### 5.5 不做

- 不做人脸照片式写实皮肤
- 不用整块表情贴图代替立体眼球/微笑（贴图仅作腮红等辅助）

## 6. 同数字块一致性检查表

交付 / 验收时勾选：

- [ ] 边长 = `1.05`，原点在底面中心
- [ ] Y-up，正面 +Z
- [ ] 身体圆角 radius=`0.16`，无锐边
- [ ] 主色 `#e85a48`，脚 `#c0392b`
- [ ] roughness≈`0.42` / metalness≈`0.06`（塑料感，非金属）
- [ ] albedo 含边缘高光/顶部高光条（或视觉等价）
- [ ] 立体双眼 + 立体微笑（非纯贴图脸）
- [ ] 右下「1」徽章可读
- [ ] 一对小脚，对称站姿
- [ ] 三角面 < **8k tris**（含五官）
- [ ] 材质尽量合批（目标 ≤ 6 个材质槽）
- [ ] 文件为 glTF 2.0 Binary（`.glb`），贴图内嵌
- [ ] 无版权素材嵌入（几何/贴图/字体原创）

## 7. 导出约定

| 项 | 约定 |
|---|---|
| 格式 | glTF 2.0 Binary（`.glb`） |
| 轴向 | **Y-up**，正面 **+Z** |
| 单位 | 1 单位 ≈ 1 米（游戏内按 `size=1.05` 使用） |
| 面数 | 角色单体目标 **< 8k tris** |
| 贴图 | 内嵌；albedo sRGB；粗糙度/法线 linear；建议 256–512 |
| 动画 | 本轮可不含；呼吸/拾起由玩法驱动 |
| 路径 | `/workspace/number-blocks/assets/models/one.glb` |
| 预览 | `/workspace/number-blocks/assets/previews/one.png` |
| 后续公开目录 | `public/models/one.glb`（脚手架侧拷贝） |

命名：kebab-case；数字角色英文 `one.glb`、`two.glb` …
