# 第一关策划案 · 第 1 集「One / 一」

> 面向新仓库（Vite + Three.js）。儿童向（约 3–6 岁），目标 **30 秒内可通关**，手机竖屏 + 桌面。  
> 交付：关卡策划 → 小灵汇总。本关**不**做探索三件套（太阳/树/蜜蜂），留给后续加长版。

---

## 1. 教学目标

- 认识数字块 **「一」**：红色圆角积木 = 数量 1。
- 建立基础操作：**点选 / 拖到目标位**。
- 通关反馈：放到正确位置 = 成功（无惩罚失败）。

## 2. 场景元素（极简）

| 元素 | 说明 |
|------|------|
| 草地小场景 | 平坦或微起伏草地 + 柔和暖光（可程序化，不要求建模） |
| **One 标准块** | 红色「一」角色块，可拖；开场站在画面左侧偏中 |
| **目标台（pad）** | 地面光圈/落点台，带「1」标识，固定在右侧偏中 |
| 可选装饰 | 1～2 朵小花或远山雾（程序化即可，非本关必建模） |

相机：略俯视固定机位（或极轻推镜一次后锁定），保证块与目标台同屏、热区够大。

## 3. 交互规则

1. **开场（≤3s）**：标题卡「第一集 · 一」→ 点「开始」进关；首次点击解锁音效。
2. **引导**：One 轻跳/呼吸；目标台脉冲高亮；一句提示：「把『一』拖到光圈上」。
3. **操作**：
   - 点击或按住拖拽 One（触摸与鼠标同一套）。
   - 拾起时块抬高；松手时若落在目标台有效半径内 → 吸附居中；否则弹回起点并轻提示「再拖到发光的圈圈里」。
4. **禁止**：无倒计时失败、无生命值、无错误次数上限。

## 4. 通关条件

- One 成功吸附到目标台 **一次** 即通关。
- 通关：短庆祝（缩放弹跳 / 简易彩带即可）+ 成功音 + 结束卡。
- 结束卡按钮：「再玩一次」（重开关内状态）、「下一集」（若未开放则灰显「准备中」）。

## 5. 失败 / 重试

- **无失败态**。放错只弹回 + 一句提示，可无限重试。
- 「再玩一次」重置块位置与引导高亮。

## 附录 B · 给音效的触发点清单

风格：儿童友好、明亮、不刺耳；音量可静音；需先 `unlock`（首次用户手势）。

| 触发点 ID | 何时 | 预期听感 | 备注 |
|-----------|------|----------|------|
| `ui.click` | 点「开始」/结束卡按钮 | 轻脆 UI 咔哒 | 短 |
| `block.pickup` | 开始拖 One | 轻轻拿起 | 短 |
| `block.place_fail` | 松手未进目标台、弹回 | 软弹/唔 | 短；可与 putdown 共用变体 |
| `block.place_success` | 吸附到目标台 | 清脆「落稳」+ 轻微确认 | **通关前置** |
| `level.clear` | 通关庆祝 | 明亮短和弦 / 成功铃声 | 与 place_success 可衔接，勿过响 |

本关**不需要**：BGM（可后期加极轻循环）、语音旁白、数数「一」单独音（若实现方便可作 place_success 装饰，非必须）。
