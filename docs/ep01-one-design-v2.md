# 第一关加厚策划 · 第 1 集「One / 一」（v2）

> 替代仅「一次拖放」的 v1。仍一集=一关；儿童 3–6 岁；手机+桌面；目标 **约 60～90 秒**通关。  
> 教学灵感（原创实现，非 BBC 素材）：「一」= 单个事物；先**认出**，再**点出**三样「一个」，最后把「一」**安放**到光圈。

## 教学目标

1. 认识红色数字块「一」。
2. 理解「一」表示**只有一个**（点选场景里三件「一个××」）。
3. 巩固拖放：把「一」放到发光光圈（家/站位）。

## 阶段（改哪些）

| 阶段 | 名称 | 做什么 | 通关本段 |
|------|------|--------|----------|
| 0 | TITLE | 标题卡「第一集 · 一」→「开始」 | 点开始 |
| 1 | MEET | One 出场轻跳；气泡「我是一！」；提示「先去找找，哪里只有一个？」 | 自动 2～3s 或点一下 One 进入 FIND |
| 2 | FIND | 场景 3 个可点目标（**一朵花 / 一只蜜蜂 / 一轮太阳**）；点中显示「1」徽章+短提示「一个××」；进度点 0/3→3/3 | 点满 3 个 |
| 3 | HOME | 提示「把『一』拖到光圈上」；光圈脉冲；拖到 pad 吸附 | 成功吸附一次 |
| 4 | CLEAR | 气泡「一个奇妙的世界，还有一个我！」；彩带；结束卡「太棒了！」 | — |

**相对 v1 的变化**：新增 MEET + FIND（2～3 个交互小目标）；HOME 保留原拖放；结束卡保留。禁止倒计时失败/生命值。

## 场景与资产

| 资产 | 本轮 | 说明 |
|------|------|------|
| `one.glb` | **沿用定稿 v9** | 可拖角色 |
| `pad.glb` | **沿用定稿 v5** | HOME 落点 |
| 花 / 蜜蜂 / 太阳 | **先程序化占位** | FIND 可点；列给建模作 P1：`flower.glb` / `bee.glb` / `sun.glb` |
| 草地/远山 | 程序化 | 可保留现有 meadow |

布局：One 左偏中；pad 右偏中；花/蜂/太阳分散且同屏或轻摇镜头仍可点（手机大热区）。

## 通关条件（整关）

FIND 完成 **且** HOME 吸附成功 → CLEAR。放错仅弹回。再玩一次重置全部阶段与进度。

## 音效触发（在原 5 点上扩展，供音效岗）

`ui.click` / `block.pickup` / `block.place_fail` / `block.place_success` / `level.clear`  
新增：`prop.tap`（点到花/蜂/太阳）、`find.progress`（每点中一个）、`find.complete`（3/3）。

## 验收

- 桌面鼠标 + 触控都能点 FIND、拖 HOME。
- 不跳过 FIND 不能进通关（除非调试）。
- 无太阳/树/蜜蜂「探索旧版」的硬编码旁路；本关即上述五阶段。
