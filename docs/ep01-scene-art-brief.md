# 第一关 · 场景/道具清单（给积木建模）

> 玩法骨架：TITLE→MEET→FIND(3/3)→HOME→CLEAR（PR #2，**不合 main**）  
> 气质目标：类塞尔达精致 3D，但仍是**儿童软塑料积木世界**（明亮、圆润、非写实）。  
> 坐标：Y-up，One 正面朝 +Z（朝相机）。世界单位 ≈ 米；One 边长 `1.05`。

## 1. 镜头 / 活动半径

| 项 | 值 |
|---|---|
| One 出生 `HOME` | `(-1.02, 0.02, 0.08)` |
| Pad `PAD` | `(1.05, 0, -0.04)`；吸附半径 `0.9` |
| 舞台暗示圈 | 地面圆心原点、半径约 `3.15`（活动主区） |
| One 活动 | 地面拖放；勿出主区；勿被装饰物挡死拖动路径 |
| 相机（stage） | 朝向近似 `(0.04, 1.08, 1.52)`；look ≈ `(0, 0.66~0.72, 0)` |
| FOV | 竖屏约 `34°`，横屏约 `30°`；手机保证花/蜂/日同屏可点 |

## 2. 必出道具 + 数量

| 资产 | 数量 | 复用 | 放置（现网占位） |
|---|---|---|---|
| `flower.glb` | **1** | 单模即可 | `(0.28, 0, 1.42)` |
| `bee.glb` | **1** | 单模即可 | `(0.06, 0.78, -1.02)`（空中） |
| `sun.glb` | **1** | 单模即可 | `(1.08, 1.28, -1.32)`（偏远/偏高） |
| `one.glb` / `pad.glb` | 已定稿 | **不重做** | v9 / v5 |

装饰配额（建议，可微调）：

- 树：**2～3**（中远景，不挡 FIND 热区与 pad）
- 石块：**3～5**（矮、圆润）
- 草丛簇：**6～12**（可合批/实例；主舞台内宜疏）
- 远山/地平线：可继续低模山丘或烘焙进背景；**不要**塞满近景

## 3. 交互语义

| 物 | 语义 |
|---|---|
| 花 / 蜂 / 日 | **可点**（FIND）；点中出「1」徽章；**不采摘、不物理撞开、不挡拖拽** |
| One | **可拖**（HOME） |
| Pad / 光圈 | **落点吸附**（非点选道具） |
| 树 / 石 / 草 / 山 | **纯装饰**；不可点、不可撞玩法、不挡 One 拖到 pad |

Bee 动线：要有**轻浮空 + 振翅**（现网：y 振幅约 `±0.08`，翅快闪）。允许小范围 8 字/徘徊，但**全程可点、不飞出竖屏框**。Sun 可慢自转光晕；花可轻微摇曳。

## 4. 色温与时段

**晴午偏暖的清晨→上午**（现网接近）：天蓝 `#9ecff2` → 地平暖白 `#f4efe6` / `#ffe4c6`；主光偏暖白 `#fff4e6`。  
不要傍晚橙红、不要阴天灰蓝、不要强对比电影光。儿童可读优先。

## 5. 性能预算（手机优先经验值）

| 项 | 目标 |
|---|---|
| One | 已定：**< 8k tris**，材质 ≤6 |
| 单道具 flower/bee/sun | 各 **≤ 4k tris**（sun 可到 5k）；材质 ≤6 |
| 树（单棵） | **≤ 3k**；石 **≤ 1k**；草丛用合批/实例 |
| 整关同屏 | 角色+道具+装饰合计约 **≤ 50k tris**；Draw call 经验 **≤ 80～100** |
| 阴影 | 保留 **1** 盏 key Directional；贴图 1k～2k 可接受 |
| 格式 | glTF 2.0 Binary；贴图内嵌 256～512；塑料 PBR（rough≈0.4，metal≈0.05） |
